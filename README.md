# 지혜섬 탐험대

초등학생을 위한 만화 스토리형 학습 웹앱입니다. 첫 화면에서 과목을 고르고, 과목 → 학년 → 지역(과정) → 화(만화·해 보기·연습 문제 5개·도전 단계) → 대장 문제로 이어집니다.

### 도전과 성취 장치

- **경험치와 레벨**: 문제를 맞히면 경험치(첫 시도 10, 연속 정답 콤보 보너스, 힌트 뒤 4)를 받고, 레벨과 칭호(새싹 탐험가 → 전설의 탐험가)가 올라요
- **콤보**: 첫 시도에 연속으로 맞히면 🔥 콤보가 쌓여요
- **도전 단계**: 화에서 별 2개 이상 받으면 열려요. 하트 3개, 힌트·셈이 도움 없이 5문제(국어·영어는 직접 쓰기·받아쓰기, 과학은 "틀린 설명 찾기")를 버티면 🏅 메달
- **오늘의 도전**: 날짜마다 바뀌는 5문제, 하루 한 번 보너스 경험치 40, 연속 학습일 🔥 기록
- **스피드 도전**: 과목·학년별 60초 동안 많이 맞히기, 최고 기록 저장
- **배지 23개와 트로피 방**: 첫걸음, 별 수집가, 과목 정복, 10콤보, 일주일 연속, 메달 10개 등
- 1·2학년은 다음 문제를 자동으로 읽어 주는 옵션이 있어요

- 수학 1~6학년 49화(학년이 곧 레벨 Lv.1~Lv.6), 국어 1~3학년 9화, 영어 3~5학년 9화, 과학 3~5학년 9화: 전체 76화
- 수학 학년별: 1학년 8화, 2학년 8화, 3학년 14화, 4학년 6화, 5학년 7화, 6학년 6화
- 국어 받아쓰기와 영어 단어·문장은 소리를 듣고 풀어요(브라우저 음성 합성)
- 과목별 리서치와 설계: `RESEARCH.md` 8장
- 지역마다 대장 문제 1개: 전체 22개(크리스탈 22개)
- 화별·단원별 문제지와 정답·풀이지(인쇄 가능), 오답 노트, 학습 기록(부모님용), 아이별 프로필, 읽어 주기
- 리뷰 반영 기록: `REVIEW.md`

- `index.html` — 앱 전체(외부 라이브러리 없음, 단일 파일)
- `manifest.webmanifest`, `sw.js`, `icon*` — 홈 화면 설치·오프라인용 PWA 파일
- `RESEARCH.md` — 학습지 리서치와 설계 노트

## 운영 주소 (GitHub Pages)

`main` 브랜치에 반영되면 GitHub Actions가 자동으로 테스트하고 배포합니다.

- 주소: https://limchaekuk-zzz0903.github.io/Elementaryschoolworksheets/
- 워크플로: `.github/workflows/pages.yml`
  - push·PR마다 `tests/e2e.js` 실행(문제 생성기 검사, 전체 화와 대장 문제 풀이, 오답 흐름, 오답 노트·학습 기록·프로필, 문제지·풀이지 일치, 질의응답, 모바일 레이아웃)
  - `main`에서 테스트를 통과하면 앱 파일만 모아 Pages로 배포
  - 배포마다 서비스 워커 캐시 이름이 커밋 SHA로 바뀌어, 설치된 앱도 새 버전을 받습니다
- **처음 한 번만**: 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 설정해야 합니다.
- 수동 재배포: Actions 탭 → "Test and deploy to GitHub Pages" → Run workflow

배포된 주소에서는 질의응답이 **기본 도움말 모드**로 동작합니다(AI 셈이는 Claude 아티팩트 안에서만 동작).

## 테스트

```bash
cd tests
npm install && npx playwright install chromium
npm test
```

## 로컬 실행

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

`index.html`을 바로 열어도 동작합니다(이 경우 오프라인 캐시는 꺼집니다).
진도는 브라우저 localStorage에 저장됩니다.

## 셈이에게 물어보기 (질의응답)

화면 오른쪽 아래 버튼이나 문제 카드의 "셈이에게 물어보기"로 질문할 수 있습니다.

- **AI 모드**: Claude 아티팩트로 열면 `sample` 기능으로 Claude가 대답합니다(첫 질문 때 사용 허락을 묻고, 보는 사람의 Claude 계정을 씁니다). 지금 보는 문제·상태·힌트를 함께 보내고, 풀이가 끝나기 전에는 정답을 말하지 않도록 지시합니다.
- **기본 도움말 모드**: 그 외 환경(로컬 실행, 허락 거절)에서는 낱말(분모, 나머지, 올림, 힌트 등)에 맞춰 내장 설명으로 대답합니다. 대화는 저장하지 않습니다.

## catalog.json (오늘우리집 서버용)

`catalog.json`은 과목 → 학년 → 지역 → 화 목록이에요. 오늘우리집 서버가 이 파일로 앱의 과목 메뉴, 과목별 진도, 시작 화면 검사를 해요.
과목이나 화를 바꾸면 `node tools/catalog.js`로 다시 만들어 함께 커밋하세요(CI가 최신인지 검사해요).
